# 키워드 사전 v2 (이슈 #61)

`config/keywords.csv`를 v1에서 v2로 올린 기록이다. 후보는 `docs/policy_cross_review.md` §4, 뉴스 검토(`docs/news_quality_review.md`, `docs/news_cross_review.md` §5)에서 나왔다. v1의 구성과 선정 근거는 `docs/dictionary_v1.md`에 있다.

## 1. 바뀐 것

표준 키워드 47개 → **48개**, 표기 170개 → **182개**. 모든 행의 `dictionary_version`이 `v2`다. `config/keyword_meta.csv`에 K048 설명을 더했다.

| 키워드 | 추가한 표기 | 이유 |
|---|---|---|
| 로봇 (K010) | `robotic` | 정책 사례. 영문 경계 규칙과 충돌하지 않는다 |
| 사이버보안 (K034) | `해킹`, `사이버위협`, `사이버 위협`, `침해사고`, `침해 사고` | 정책·뉴스 누락 사례 |
| 인공지능 (K001) | `artificial intelligence` | 영문 출처의 풀어 쓴 표기 |
| 슈퍼컴퓨팅 (K046) | `high-performance computing`, `high performance computing` | 정책 표본 |
| **양자기술 (K048, 새 키워드)** | `양자기술`, `양자 기술`, `quantum technology` | 양자컴퓨팅(K021)에 들어가지 않는 일반 표기 |

## 2. 반영하지 않은 후보와 이유

| 후보 | 결정 | 이유 |
|---|---|---|
| `클라우드`의 단독 `cloud` 빼기 | **보류** | 정책에서는 대기과학의 구름·`Programmable Cloud Laboratories Network` 오탐이 있었지만, 뉴스에서는 `Google Cloud 장애`처럼 실제 클라우드 기사 **2건(28건 중)이 빠진다.** B의 뉴스 표본 150건에서는 0건이었으나 이번 누적 뉴스에서는 달랐다. 정책 오탐 건수와 견주어 다시 정한다 |
| `퀀텀` 단독 | **반대** | 디스플레이 용어 `퀀텀닷`·`QD`에서 4건이 새로 잡혔고 그중 양자와 무관한 기사가 있었다. `양자기술`·`quantum technology`만 넣었다 |
| 단독 `양자` | 반대 | 물리학 일반 용어(B 의견과 같음) |
| 단독 `에이전트` | 반대 | AI 에이전트 문서가 39건 → 60건이 되지만 늘어난 21건에는 대리점·중개인 등 일반 의미가 섞여 있다 |
| `Ai` 대소문자 변형 | 반대 | 사람 이름(`Ai Weiwei` 등)이 걸릴 수 있고 이번 뉴스에서 새로 잡히는 문서도 0건이다 |
| 모델·제품 이름, `트랜스포머`, `벡터 DB` | 반대 | 제품명은 바뀌고 `트랜스포머`는 영화·완구와 겹친다 |
| `디지털 전환`의 `DX` | **유지** | B가 본 3건 중 1건이 게임 이름(`DX-Ball`)이고 2건은 `DX팀`·`DX본부장`처럼 디지털 전환 맥락이다. 빼면 그 2건을 놓친다. 오추출 사례로만 기록한다 |

## 3. 영향 문서 수 (뉴스 469건 중 분석 463건, 2026-10-21 측정)

v1과 후보 하나씩만 바꾼 사전을 같은 문서에 적용해 센 값이다(키워드별 문서 빈도). **정책 문서는 이 PC에 없어 측정하지 못했다.** 정책 쪽 근거는 B의 검토 기록(`docs/policy_cross_review.md`, `docs/news_cross_review.md`)에 따른다.

| 변경 | 대상 키워드 | v1 | v2 | 새로 잡힘 | 빠짐 |
|---|---|---|---|---|---|
| `robotic` | 로봇 | 34 | 34 | 0 | 0 |
| `해킹` | 사이버보안 | 22 | 35 | 13 | 0 |
| `사이버위협`·`침해사고` | 사이버보안 | 22 | 25 | 3 | 0 |
| (위 둘 합산) | 사이버보안 | 22 | 37 | 15 | 0 |
| `artificial intelligence` | 인공지능 | 225 | 225 | 0 | 0 |
| `high-performance computing` | 슈퍼컴퓨팅 | 1 | 1 | 0 | 0 |
| `양자기술`·`quantum technology` | 양자기술(새) | 0 | 2 | 2 | 0 |

0건은 "이 표본에서 쓰이지 않았다"는 뜻이지 불필요하다는 뜻이 아니다. `해킹`으로 새로 잡힌 13건은 대부분 보안 사고·AI 보안 기사지만, 일부(스마트TV 개조 등)는 주제와 거리가 있다. 사전 기반 방식이라 **언급이 있으면 센다.**

## 4. 재현

```bash
python src/extract_keywords.py          # document_keywords.csv 전체를 v2로 다시 만든다
python src/aggregate.py
python src/validate_csv.py --dir data/processed --sources config/sources.csv
```

한 파일에 v1과 v2가 섞이면 검증기가 오류로 처리하므로 추출 결과를 통째로 다시 만들어야 한다. 새로 만든 `document_keywords.csv`는 v2 547행이고 검증 오류 0건이었다. 테스트 328개 통과(`tests/test_dashboard.py`의 키워드 메타 개수 47 → 48 갱신).

## 5. 남은 일

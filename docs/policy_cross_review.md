# 정책 추출 결과 교차 검토 — A의 몫 (이슈 #12)

B가 만든 정책 추출 결과(`docs/policy_quality_review.md`, 이슈 #24)를 A가 독립적으로 표본 검토한 기록이다. **정확도·재현율 같은 성능 수치는 주장하지 않는다.** 별도 평가 설계 없이 본 사례 기록이다. 뉴스 결과를 B가 검토하는 쪽(이슈 #12의 나머지 절반)은 이 문서에 없다.

## 1. 방법

| 항목 | 내용 |
|---|---|
| 입력 | B가 전달한 정책 추출 결과 `policy_document_keywords_2026-10-18.csv`(키워드 54행)와 `policy_documents_meta_2026-10-18.csv`(메타 147행, 분석 완료 64건). 제목·본문은 없고 `document_id`와 원문 주소로 가리킨다 |
| 표본 | 분석 완료 64건 중 **9건** (과기정통부 5, NSF 2, DOE 1, 백악관 OSTP 1). 키워드가 잡힌 문서와 안 잡힌 문서를 섞었고 무작위(고정 시드)로 골랐다 |
| 검토 방법 | 각 문서의 공개 원문 주소를 열어 주제와 사전 키워드 표기의 실제 등장을 읽고, B의 추출 결과와 비교했다 |
| 제외한 것 | **중국 출처(국무원, 중국과학원)는 검토하지 않았다.** `local_only_no_publish`라 제목·본문을 기록에 남길 수 없고, 이 표본에서는 열어 보지도 않았다 |
| 검토자 | A. 한 사람이 읽었고 정답 라벨은 없다 |

**한계** 표본 9건은 64건 중 일부이고 출처별로 1~5건뿐이라 출처별 경향이나 오류율을 말할 수 없다. 나는 원문 **웹 페이지**를 읽었고 추출기는 **수집된 피드·본문 텍스트**를 분석했으므로 둘이 같은 글자 수준으로 일치하지는 않는다.

## 3. 확인한 것

1. **B의 판단과 어긋나는 것은 없었다.** 표본에서 오추출은 1건(#6)이고, B가 사례 2·3으로 기록한 `cloud labs`와 **같은 유형**이다. 비ICT 문서에서 키워드가 안 잡힌 것(#4, #5, #7, #8)은 모두 맞았다.
2. **과기정통부 페이지 본문은 비어 있다.** 5건 모두 원문 페이지에 제목과 "자세한 내용은 첨부파일을 참고하시기 바랍니다"뿐이었고, 실제 내용은 첨부(HWP·PDF)에 있다. B의 한계 4("출처 간 분석 텍스트 길이가 100배 가까이 다르다")가 원문에서도 확인된다. 과기정통부는 제목과 짧은 개요에 든 키워드만 잡힌다.
3. **페이지 공통 문구(메뉴, 슬로건, 푸터)가 키워드로 새지 않았다.** 과기정통부 페이지에는 "AI로 디지털 대전환…" 같은 공통 문구가 많은데(웹 페이지 도구로 센 대략치로 인공지능 9~20회, 디지털 전환 약 7회가 메뉴·슬로건에서 나옴), 비ICT 문서 #4, #5에서 키워드가 하나도 안 잡힌 것은 추출이 본문 텍스트만 읽었다는 뜻이다. 정제가 맞게 동작한다.
4. **사전 쪽 문제는 뉴스 쪽에서 본 것과 겹친다.** 단독 `cloud` 표기가 클라우드로 잡히는 문제(뉴스 쪽 사례에는 없었으나 정책의 과학 출처에서 반복), 영문 풀어 쓴 표기 누락(`high-performance computing`)이 같은 계열이다.

## 5. 남은 한계 (공개)

1. 표본이 작고(9건) 한 사람이 읽었다. 이 기록으로 오류율을 계산할 수 없다.
2. 중국 출처는 검토하지 않았다.
3. 웹 페이지를 읽었으므로 추출기가 분석한 텍스트와 완전히 같지 않다. 특히 과기정통부는 페이지 본문이 비어 있어 B가 수집한 개요 텍스트와 비교할 수 없었다.
4. OSTP 1건(#9)은 열어 보지 않았다.
5. 뉴스 결과를 B가 검토하는 절반은 아직 없다(이슈 #12의 B 몫).

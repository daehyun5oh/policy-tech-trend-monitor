# 키워드 사전 v3 — 정책 용어 보강 (2026-10-22)

v2(`docs/dictionary_v2.md`)에서 정책 문서에 쓰이는 용어를 더했다. 정책 화면이 비어 보이는 원인을 찾으려고 **키워드가 하나도 안 잡힌 정책 문서 57건(분석 112건 중)을 읽고** 후보를 정했다. 표기 182개 → **204개**, 키워드 48개 → **49개**. 모든 행의 `dictionary_version`이 `v3`다.

## 1. 바뀐 것

| 키워드 | 추가한 표기 | 새로 잡힌 문서(정책/뉴스) | 비고 |
|---|---|---|---|
| 양자기술 (K048) | `양자통신`, `양자 통신`, `양자(퀀텀)`, `양자암호`, `양자 암호` | 2 / 0 | 과기정통부 양자통신·양자 개발그룹 보도자료 |
| 양자기술 (K048) | `quantum` | 8 / 0 | 영문 정책 문서(NSF·OSTP·DOE)의 양자 언급. 영문 `quantum`은 물리학 일반 용어일 수 있어 한 문서 안에서 스치는 언급도 센다 |
| 반도체 (K018) | `integrated circuit`, `집적회로`, `IC layout` | 1 / 0 | 중국 집적회로 배치설계 보호 규정 |
| 대규모 언어 모델 (K003) | `frontier AI`, `foundation model` | 4 / 0 | 미국 정책 문서 |
| **AI 거버넌스 (K049, 새 키워드)** | `AI 거버넌스`, `AI governance`, `AI 기본법`, `인공지능 기본법`, `AI 안전`, `AI safety`, `AI 윤리`, `AI ethics`, `trustworthy AI`, `responsible AI`, `AI 규제` | 2 / 5 | 정책의 핵심 주제. 뉴스에서는 AI 안전 법안 기사 |

영향 문서 수는 후보 하나씩만 바꾼 사전을 같은 문서(정책 112건, 뉴스 463건)에 적용해 센 값이다. `quantum`은 새로 잡힌 문서 중 일부가 주제와 거리가 있다(조직 소개 페이지 등). 사전 기반이라 **언급이 있으면 센다.**

## 2. 반영하지 않은 후보

| 후보 | 이유 |
|---|---|
| `디지털 정부`, `전자정부`, `공공데이터` | 새로 잡힌 문서가 뉴스 1건뿐 |
| `broadband`, `spectrum`, `주파수`, `통신망` | 영문 `spectrum`이 얼굴 위변조 탐지 기사에 걸려 오탐. 정책 쪽 새 문서도 1건 |
| `3D printing`, `적층제조` | 새로 잡힌 문서 3건 중 ICT 주제가 아닌 팟캐스트·협정문. ICT 범위 밖 |
| `SMR(소형 모듈 원자로)`, `희토류`, 환경·천문·생명과학 용어 | **ICT가 아니다.** 사전이 아니라 수집 범위의 문제 |

## 3. 알게 된 것: 정책 문서가 비어 보이는 가장 큰 이유

키워드가 안 잡힌 정책 문서 57건을 읽어 보니 대부분 **사전에 용어가 없어서가 아니라 ICT 문서가 아니었다.** 시상식·과학관 행사·천문 올림피아드(과기정통부), 환경·법무·역사문화도시 규정(국무원), 수상·학술 단체 소식(중국과학원), 송전선·연료 세액공제(DOE)다. 이번 보강으로 키워드가 있는 정책 문서는 **55건 → 59건**으로 4건 늘었을 뿐이다.

따라서 정책 화면을 채우는 방법은 사전을 더 늘리는 것이 아니라 (1) ICT와 무관한 문서를 가려내는 규칙(`docs/topic_filter_rules.md`, 설계 단계)이나 (2) ICT 비중이 높은 출처를 더하는 것이다. 이 사전은 여전히 초안이며 정확도·재현율은 측정하지 않았다.

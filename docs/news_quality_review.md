# 뉴스 추출 품질 검토 (이슈 #23, 완료 기준 C5)

실제 뉴스에서 키워드 추출이 놓치거나 잘못 잡은 사례를 기록하고 한계를 공개한다. **정확도·재현율 같은 성능 수치는 주장하지 않는다.** 별도 평가 설계 없이 본 사례 기록이다.

## 1. 검토 대상

| 항목 | 내용 |
|---|---|
| 자료 | 긱뉴스 Atom 피드 (2026-10-17 수집, 발행일 2026-10-01~31 필터) |
| 수집 결과 | 50건 수집, 50건 분석, 제외 0건 |
| 분석 범위 | 49건은 피드 요약(`title_summary`), 1건은 요약이 비어 제목(`title`)만 |
| 사전 | `config/keywords.csv` v1 (표준 키워드 47개) |
| 검토 방법 | 50건 전부를 제목·요약과 추출 결과를 나란히 놓고 훑은 뒤, **눈에 띈 사례 10건**을 아래에 기록 |
| 검토자 | A (뉴스 결과는 B가 교차 검토하기로 한 이슈 #12 몫이며 아직 하지 않음) |

**한계** 10건은 무작위 표본이 아니라 누락·오추출이 의심되는 사례를 골라 적은 것이다. 이 표에서 오류율을 계산할 수 없다. 판단 기준은 검토자 한 사람의 읽기이며 정답 라벨이 없다.

참고로 50건 중 키워드가 하나 이상 잡힌 문서는 13건(17행)이다. 긱뉴스는 개발자 대상 기술 소식이라 디지털·ICT 정책 키워드와 겹치는 비중이 낮다.

## 2. 기록한 사례 10건

유형: **누락**(있어야 할 키워드가 안 잡힘), **오추출**(잘못 잡힘), **범위**(잡히긴 했으나 해석에 주의), **판단 보류**(사전 설계 문제인지 불분명)

| # | 문서(제목) | 추출 결과 | 관찰 | 유형 | 원인 |
|---|---|---|---|---|---|
| 1 | Ask GN: Ai 브라우저의 필수적인 기능 | 없음 | 제목과 본문이 "Ai 브라우저"라고 써서 인공지능 키워드를 놓침 | 누락 | `AI`는 대소문자를 구분하는 표기(약어 오탐 방지, 규칙 문서 참조)라 `Ai`가 안 걸림 |
| 2 | Self-Evolving Agent Harness - 모델은 그대로, 하네스를 스스로 고치는 에이전트 | 없음 | 에이전트가 주제인데 `AI 에이전트` 키워드가 안 잡힘 | 누락 | 사전에 `AI 에이전트`, `agentic AI` 등만 있고 단독 `에이전트`는 없음 |
| 3 | Claude Code 팀의 코드 리뷰 방식 | 없음 | AI가 코드를 90% 쓰는 팀 이야기지만 요약에 "AI"라는 낱말이 없고 "Claude"만 나옴 | 누락 | 제품·모델 이름(Claude, GPT, Gemini)은 사전에 없음 |
| 4 | Claude, 25년간 풀리지 않았던 NIST 타원곡선 암호 시드의 출처 규명 | 없음 | AI가 암호 수수께끼를 푼 소식이나 둘 다 안 잡힘 | 누락 | 제품 이름 누락(위와 같음). 암호·난수 관련 키워드는 사전 범위에 없음 |
| 5 | NIST 타원곡선 시드 생성의 수수께끼가 풀려 현상금 지급 | 없음 | 암호 표준 소식이지만 보안 키워드가 없음 | 판단 보류 | 사전의 `사이버보안`은 "보안·정보보호" 계열 표기만 가짐. 암호학 용어는 포함하지 않았음 |
| 6 | 메모리에서 출발해 트랜스포머를 발명할 수도 있었다 | 없음 | 셀프 어텐션·MLP 등 딥러닝 구조 이야기인데 `딥러닝`이 안 잡힘 | 판단 보류 | 문서가 "딥러닝"이라는 낱말을 쓰지 않음. 사전은 표기 일치만 보므로 관련 개념어(트랜스포머, 어텐션)는 범위 밖 |
| 7 | Show GN: livero - 48KiB RAM에서 도는 인덱스 없는 온디바이스 벡터 DB | 없음 | 온디바이스·벡터 DB 소식이나 안 잡힘 | 판단 보류 | 사전의 `온디바이스 AI`는 "AI"가 붙은 표기만 인정. 벡터 DB 키워드 없음 |
| 8 | Big Fish: OpenBSD의 37년 된 커널 버그 악용하기 | 없음 | 권한 상승 취약점 분석이나 보안 키워드가 없음 | 판단 보류 | `사이버보안` 표기에 "취약점"·"보안" 단독 낱말이 없음(오탐 방지) |
| 9 | Show GN: 여울게임터 - 가입 없이 브라우저에서 바로 하는 게임 공유 사이트 | 인공지능(`AI` 1회) | 요약에서 "AI 도움을 받아 만들었다"고만 말함. 문서의 주제는 게임 사이트 | 범위 | 단어 일치일 뿐 문서가 AI를 다루지는 않음. 문서 빈도에 1건으로 잡힘. 사전 기반 방식의 구조적 한계 |
| 10 | Anthropic, 6월에 투기등급 중 가장 높은 신용등급 받아 | 없음 | 피드 요약이 비어 **제목만** 분석함 | 범위 | `analysis_scope=title`. 요약이 비는 문서는 키워드를 놓칠 가능성이 크다. 화면에서 분석 범위를 구분해 보여야 함 |

## 3. 나머지 문서에서 확인한 것

- **잘 잡힌 예**: Waymo 토론토 진출 → 자율주행(3회), NVIDIA Run:ai → 인공지능·GPU(4회)·오픈소스, Postgres 19 지연 → 인공지능·대규모 언어 모델.
- **오추출(잘못 잡힘)은 이번 50건에서 찾지 못했다.** 다만 위 #9처럼 "언급은 했지만 주제는 아닌" 경우는 현재 방식으로 구분할 수 없다.
- 피드 요약 일부는 문장 중간에서 끊겨 있다. 요약에 없는 내용은 분석되지 않는다.

## 4. 개선 내역

| 구분 | 내용 | 상태 |
|---|---|---|
| 반영함 | 제목과 요약·본문을 따로 매칭해 합침. 제목 끝과 본문 첫머리가 이어져 `양자 컴퓨팅`처럼 잘못 붙는 일치를 막음 | 반영됨(`analyze_segments`, 테스트 있음) |
| 반영함 | 수집기가 요약이 없는 문서를 `analysis_scope=title`로 기록해 범위를 구분 | 반영됨 |
| 제안(미반영) | 대소문자 변형 `Ai`를 `인공지능` 표기에 추가할지 검토 | 사전 v2 후보 |
| 제안(미반영) | `AI 에이전트`에 단독 `에이전트` 추가 검토 (일반 용어라 오탐 위험 확인 필요) | 사전 v2 후보 |
| 제안(미반영) | 모델·제품 이름(Claude, GPT, Gemini 등) 또는 `트랜스포머`, `벡터 DB`, 암호·보안 용어 추가 검토 | 사전 v2 후보, 정책 쪽 용어와 함께 B와 합의 |

사전 변경은 `dictionary_version`을 올리고 fixture 기대값에 영향이 없는지 확인한 뒤 적용한다. 이번 검토에서는 B와 합의 없이 사전을 바꾸지 않았다.

## 5. 남은 한계 (공개)

1. 사전 표기 일치 방식이라 철자 변형·약어·제품명·관련 개념어를 놓친다. 정확도나 탐지 성능은 측정하지 않았다.
2. 문서에 단어가 한 번만 나와도 1건으로 센다. 주제와 무관한 언급을 가려내지 못한다.
3. 긱뉴스는 개발자 커뮤니티라 정책·ICT 산업 뉴스와 성격이 다르다. 이 결과를 다른 뉴스 출처로 일반화할 수 없다.
4. 피드가 최신 약 50건만 줘서 검토 표본이 작고 기간도 하루 단위로 좁다.
5. 검토자가 한 사람이고 교차 검토(#12)를 거치지 않았다.

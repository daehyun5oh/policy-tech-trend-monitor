# 출처 이용 조건 기록

기획안 §11에 따라 출처별 이용약관·접근 허용 범위·재배포 범위를 확인해 남기는 문서다. **확인 전에는 수집하지 않는다.**

**담당** 정책 출처는 B, 뉴스 출처는 A. 기록 양식과 판단 기준은 공통으로 쓴다.
**관련 이슈** #2 (정책 출처·수집 기간·이용조건 확정), 완료기준 C1

## 1. 지켜야 할 선

- 로그인·유료·접근제한을 **우회하지 않는다**
- 출처가 안내한 호출 제한과 수집 간격을 따른다. 실패해도 과도하게 재시도하지 않는다
- **열람·수집 가능 여부**와 **재배포 가능 여부**를 구분해 판단한다. 읽을 수 있다고 다시 배포할 수 있는 것은 아니다
- 공개 저장소에는 공개 가능한 메타데이터·집계값·샘플만 넣는다. 원문 전문은 `data/raw/` 에 두고 추적하지 않는다
- 불필요한 개인정보를 수집하지 않는다
- **제공자가 기계적 수집 경로를 닫은 출처는, 다른 경로로 대체 수집하지 않는다**

마지막 항목은 이번 확인에서 추가했다. 근거는 §4의 정책브리핑 사례다.

## 2. 확인 상태 표기

| 값 | 뜻 |
|---|---|
| `unverified` | 접근 경로를 확인하지 않음 |
| `access_ok` | **페이지가 열리고 목록을 읽을 수 있음**을 확인. 약관은 별개 |
| `access_ok_stale` | 열리지만 갱신이 멈췄거나 매우 느림 |
| `terms_ok` | 약관까지 확인하고 수집·이용 범위가 정해짐. **이 상태만 수집 가능** |
| `blocked` | 약관 또는 기술적 제약으로 수집 불가 판정 |

**현재 `terms_ok` 는 0곳이다. 아직 어느 출처도 수집할 수 없다.**

## 3. 국가별 저작권 판단 기준

세 나라의 기준이 서로 달라, 같은 잣대로 판단할 수 없다.

### 한국 — 공공누리(KOGL)

저작권법 제24조의2(공공저작물의 자유이용)에 따라, 공공누리 표시가 **부착된** 자료는 별도 허락 없이 이용할 수 있다. 유형별 조건이 다르다.

| 유형 | 조건 |
|---|---|
| 제1유형 | 출처표시 (상업적 이용·변경 가능) |
| 제2유형 | 출처표시 + 상업적 이용금지 |
| 제3유형 | 출처표시 + 변경금지 |
| 제4유형 | 출처표시 + 상업적 이용금지 + 변경금지 |
| AI유형 | 인공지능 학습용 데이터로 이용 가능. 단 유사 산출물 방지 조치, 직접 인용 시 출처표시 조치, 학습용 데이터 재판매 금지 |

**중요** 표시가 **부착되지 않은** 자료는 자유이용 대상이 아니며 담당자와 사전 협의가 필요하다. 유형은 **자료마다 다를 수 있어** 건별로 확인해야 한다.

제1~4유형은 출처(발행연도, 기관명, 홈페이지 URL, 작성자명이 표시된 경우 그 성명)를 반드시 표시해야 한다.

### 미국 — 연방정부 저작물

미국 연방정부가 작성한 저작물은 미국 저작권법(17 U.S.C. §105)상 저작권 보호 대상이 아니어서 대체로 자유롭게 이용할 수 있다. **다만 예외가 있다.**

- 계약자·수탁기관이 작성한 부분
- 기관 로고·상표 (NSF는 Brand Standards로 별도 규율)
- 제3자가 저작권을 가진 사진·그림

NSF의 Policies 목록(`nsf.gov/policies`)에는 저작권 전용 안내가 없다. **건별 확인이 필요하다.**

### 중국 — 명시적 재배포 금지

국무원 영문판(`english.www.gov.cn`) 푸터에 아래가 명시돼 있다.

> All rights reserved. The content (including but not limited to text, photo, multimedia information, etc) published in this site belongs to www.gov.cn. Without written authorization from www.gov.cn, such content shall not be republished or used in any form.

**서면 허가 없이는 재배포하거나 어떤 형태로도 이용할 수 없다**는 문구다. 중국과학원 영문판도 `Copyright © 2002 - 2026 Chinese Academy of Sciences` 표시만 있고 이용 허락 조건이 없어, 기본값은 무단 이용 불가다.

**판단 필요** 문구의 "used in any form" 범위가 넓어, 제목을 공개 저장소에 올리는 것조차 안전하지 않을 수 있다. §6에 선택지를 정리했다.

## 4. 출처별 기록

### 한국

#### policy-kr-001 / 002 / 003 — 과학기술정보통신부

| 항목 | 내용 |
|---|---|
| 접근 방식 | **공식 RSS 16종 제공** (`RSS 이용안내` 페이지에 주소 공개) |
| 사용할 피드 | 보도자료 `bbsSeqNo=94`, 과학기술정책 `70`, 주간동향·간행물 `81` |
| 목록 페이지 | `msit.go.kr/bbs/list.do?sCode=user&mPid=208&mId=307` (보도자료, 총 17,625건) |
| 이용약관 위치 | `msit.go.kr/contents/cont.do?sCode=user&mPid=147&mId=161` (저작권정책) |
| 재배포 범위 | 공공누리 부착 자료는 유형별 조건에 따라 가능. **자료마다 유형이 다름.** 미부착 자료는 사전 협의 |
| 호출 제한 | 안내 없음. `.env` 의 `POLICY_REQUEST_DELAY_SEC` 로 간격을 두고 수집 |
| 인증 필요 | 불필요 |
| 확인일·확인자 | 2026-10-17, B |
| 판정 | **`access_ok`** — 공공누리 유형 건별 확인 절차를 정하면 `terms_ok` 로 갈 수 있다 |

**구현 시 처리할 것 4가지**

1. 피드 1회 응답이 **50건**. 그 이전 자료는 목록 페이지 페이징이 필요
2. `pubDate` 가 `2026.10.15` 형식. 데이터 사전의 `YYYY-MM-DD` 로 변환 필요
3. `content:encoded` 본문에 **한글(HWP) 메타데이터 JSON이 혼입**. 정제 단계에서 제거 규칙 필요
4. 목록에 **담당자 이름과 연락처가 노출**. 기획안 §11에 따라 수집·저장하지 않는다

#### policy-kr-004 — 정책브리핑 (korea.kr)

| 항목 | 내용 |
|---|---|
| 접근 방식 | **RSS 서비스 2026-07-01 중단** |
| 중단 사유 | 공지 원문: "콘텐츠 저작권 등 권리 보호에 따른 제공방식 변경" |
| 공지 위치 | `korea.kr/etc/noticeView.do?newsId=132038885` |
| 이용약관 위치 | `korea.kr/guide/copyRight.do` |
| 재배포 범위 | 공공누리 **제1유형(출처표시)** 이 부착된 텍스트는 자유이용. 출처를 구체적으로 표시해야 함 |
| 제외 대상 | 사진은 정부기관·연합뉴스 등, 이미지는 통로이미지(주)에 저작권. **공공누리가 부착돼도 사진·이미지는 사전 협의 필요** |
| 확인일·확인자 | 2026-10-17, B |
| 판정 | **수집 보류 — 제외 권고** |

**제외를 권고하는 이유** 제공자가 **저작권 보호를 사유로 기계적 수집 경로(RSS)를 스스로 닫았다.** 같은 자료를 HTML 스크래핑으로 대체 수집하는 것은 제공자의 의도에 반할 소지가 크다. 꼭 필요하면 정책포털과(044-203-3052)에 사전 문의하는 편이 맞다.

#### policy-kr-005 — KISTEP 발간물

| 항목 | 내용 |
|---|---|
| 접근 방식 | 목록 페이지 `kistep.re.kr/reportAllList.es?mid=a10305010000` (전체 연구보고서 1,181건) |
| 제공 정보 | 보고서명, 연구책임자·소속, 발행일, **KISTEP이 직접 부여한 키워드 태그**, 다운로드·미리보기 |
| 이용약관 위치 | 목록 페이지에서 저작권 안내 링크를 찾지 못함. **별도 확인 필요** |
| 재배포 범위 | 미확인 |
| PDF 텍스트 추출 | **미확인** — 확인에는 파일 다운로드가 필요하다 |
| 확인일·확인자 | 2026-10-17, B (부분) |
| 판정 | **수집 보류** |

**참고할 점** KISTEP이 보고서마다 키워드를 달아 둔다(예: `#인공지능 #피지컬AI #사업계획 적정성 검토`). 우리 사전 기반 추출 결과를 **대조할 기준**으로 쓸 수 있다. 완료기준 C5(추출 품질 검토)에 활용할 만하다.

## 5. 수집 기간 제안

이슈 #2의 "수집 기간 선정" 항목이 비어 있다. 아래를 제안한다.

| 안 | 기간 | 장점 | 단점 |
|---|---|---|---|
| A | 최근 **3개월** (2026-08-01 ~ 2026-10-31) | RSS 50건 한도 안에서 대체로 해결. 페이징 구현을 뒤로 미룰 수 있다 | 주간·월간 추이를 볼 구간이 짧다 |
| B | 최근 **6개월** (2026-05-01 ~ 2026-10-31) | 월간 보고서를 6개 구간으로 비교할 수 있다 | 목록 페이지 페이징 구현이 필요 |
| C | 최근 **12개월** | 계절성까지 볼 수 있다 | 수집량과 검토 부담이 커진다. 8주 로드맵에 부담 |

**B안(6개월)을 권한다.** 기획안 §5가 주간·월간 보고서를 요구하므로 월 단위 비교 구간이 최소 몇 개는 필요하고, 12개월은 시제품 범위에 과하다.

## 6. 판단이 필요한 사항

제가 사실만 모았고, 아래는 결정이 필요하다.

**① 중국 출처를 쓸지, 쓴다면 어디까지 공개할지**

국무원 영문판 문구("shall not be republished or used in any form")가 넓어 세 가지 선택지가 있다.

| 안 | 내용 | 위험 |
|---|---|---|
| 가 | 중국 출처 **제외** | 경쟁국 비교의 한 축이 빠진다 |
| 나 | **로컬 분석만.** 공개 산출물에는 집계 수치와 URL·발행일만 남기고 제목·본문은 `data/raw/` 에 보관 | 제목도 "content"에 해당할 수 있다는 해석 여지 |
| 다 | 서면 허가를 요청한 뒤 결정 | 시간이 걸린다. 8주 로드맵과 맞지 않을 수 있다 |

**나안**을 권하되, 공개 범위를 좁게 잡는 것이 안전하다.

**② 정책브리핑을 제외할지** — §4의 제외 권고에 동의하는지

**③ KISTEP PDF 다운로드 여부** — 텍스트 추출 가능 여부를 확인하려면 파일을 내려받아야 한다. 승인이 필요하다

**④ 수집 기간** — §5의 A·B·C 중 선택

**⑤ 미국 출처의 로고·사진 처리** — 본문 텍스트만 쓰고 이미지는 수집하지 않는 방침으로 정리할지

# 출처 이용 조건 기록

기획안 §11에 따라 출처별 이용약관·접근 허용 범위·재배포 범위를 확인해 남기는 문서다. **확인 전에는 수집하지 않는다.**

**담당** 정책 출처는 B, 뉴스 출처는 A. 기록 양식과 판단 기준은 공통으로 쓴다.

## 1. 지켜야 할 선

- 로그인·유료·접근제한을 **우회하지 않는다**
- 출처가 안내한 호출 제한과 수집 간격을 따른다. 실패해도 과도하게 재시도하지 않는다
- **열람·수집 가능 여부**와 **재배포 가능 여부**를 구분해 판단한다. 읽을 수 있다고 다시 배포할 수 있는 것은 아니다
- 공개 저장소에는 공개 가능한 메타데이터·집계값·샘플만 넣는다. 원문 전문은 `data/raw/` 에 두고 추적하지 않는다
- 불필요한 개인정보를 수집하지 않는다

## 2. 확인 항목

출처를 등록하기 전에 아래를 확인하고 §3 표에 적는다.

| 항목 | 확인할 내용 |
|---|---|
| 접근 방식 | 공식 API / RSS / 공개 목록 페이지 / 다운로드 자료 중 무엇인지 |
| 이용약관 위치 | 약관·이용안내 페이지 주소 |
| 수집 허용 범위 | 제목만 / 제목과 요약 / 본문까지 |
| 재배포 범위 | 메타데이터만 / 요약까지 / 원문 가능 / 불가 |
| 저작권 표시 조건 | 출처 표시 의무, 변경 금지 조건 등 |
| 호출 제한 | 분당·일당 요청 수, 권장 대기 시간 |
| 인증 필요 여부 | API 키 필요 여부. 필요하면 `.env` 변수명 |
| 확인일·확인자 | 언제 누가 확인했는지 |

약관은 바뀔 수 있으므로 **확인일을 반드시 남긴다.** 6개월이 지난 기록은 다시 확인한다.

## 3. 출처별 기록

아래 표는 `config/sources.csv` 와 짝을 이룬다. CSV에 행을 추가하면 이 표에도 추가한다.

### news-001 GeekNews (긱뉴스)

| 항목 | 내용 |
|---|---|
| 접근 방식 | 공개 Atom 피드 `https://news.hada.io/rss/news` (최신 약 50건). 피드가 닿지 않는 기간은 수동 수집 목록(`data/sample/geeknews_2026-09_input.csv`)으로 대체 |
| 이용약관 위치 | https://news.hada.io/terms , 이용 안내 https://news.hada.io/guidelines |
| 수집 허용 범위 | `robots.txt`는 AI 학습용 크롤러를 막고, 그 밖의 에이전트에는 `/api/`, `/auth/`, `/login`, `/settings/` 등만 막는다. 피드 경로는 막혀 있지 않고 푸터에서 공개 안내한다. 약관 제6조는 "과도한 부하를 주는 자동화 접근·크롤링"을 금지한다 → 피드를 **1회만** 요청하고 재시도하지 않으며 페이지 크롤링은 하지 않는다 |
| 재배포 범위 | 약관에 제3자 재사용·재배포를 허용하는 조항도 금지하는 조항도 없다. 허용 근거가 없으므로 **메타데이터(제목·URL·발행일)와 집계값만 공개**하고, 피드의 요약 텍스트는 `data/processed/texts/`(Git 제외)에만 둔다 |
| 저작권 표시 조건 | 원문 저작권은 각 링크 대상에 있다. 보고서와 화면에 원문 URL을 함께 표시한다 |
| 호출 제한 | 명시 없음. 위 1회 요청 원칙을 지킨다 |
| 인증 필요 여부 | 없음 |
| 확인일·확인자 | 2026-10-17 · A (약관 재사용 범위는 문의처 news@hada.io 로 확인 요청 필요) |
| 판정 | **피드 수집 허용(제한적)**. 재배포 범위는 미확정이라 메타데이터까지만 |

## 4. 기존 샘플 데이터에 대한 확인 필요 사항

`data/sample/geeknews_2026-09_input.csv` (1,417건, `date,title,url`)

| 항목 | 내용 |
|---|---|
| 출처 | 긱뉴스(GeekNews). `config/sources.csv` 의 `news-001` 로 등록함 |
| 담당 | A |
| 이용 조건 | 확인함(2026-10-17). §3 news-001 참조 |
| 재배포 범위 | 제목·URL·날짜만 담은 목록이며 허용 근거는 없다. 공개 유지 여부는 약관 문의 회신(news@hada.io)에 따라 결정하고, 거절되면 저장소에서 제거한다 |
| 판정 | **조건부 유지** — 문의 회신 전까지 메타데이터 목록만 둔다 |

이 파일은 이미 저장소에 커밋돼 있다(`d503ac5`). 재배포 조건을 확인하지 않은 상태라면 §1의 원칙과 어긋날 수 있어, **A 또는 저장소 소유자와 확인이 필요하다.**

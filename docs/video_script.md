# 시연 영상 대본

영상은 두 개다. **README용**(짧게, 승인 PR용)과 **LMS 제출용**(중간 과제, 고도화 전/후). 화면에는 합성 데모(공개 주소)와 터미널만 쓴다. 직접 수집한 실제 대시보드는 기사·문서 제목이 보이므로 영상에 길게 띄우지 않는다.

- 공개 데모: https://hyeon0.github.io/policy-tech-trend-monitor/
- 수업일(10/17) 시점 화면: 같은 합성 데이터로 옛 코드(`3965f54`)에서 만든 파일을 쓴다(`python dashboard/app.py --dir data/demo --out 옛화면.html --no-validate`를 옛 커밋에서 실행)
- 비교 링크: README 맨 위

## 녹화 전 준비

1. 다른 창·알림을 끈다. 터미널 경로에 사용자 이름이 보이면 `cd`로 짧은 폴더로 옮기거나 프롬프트를 지운다
2. 브라우저는 시크릿 창으로 연다(북마크·계정 표시가 안 보이게)
3. 터미널 글자를 크게 한다. 화면은 브라우저 창만 잡는다
4. 합성 데모에서는 "샘플 데이터 데모" 띠가 위에 보인다. 그대로 두고 "지어낸 자료"라고 말한다

## B. LMS 제출용 영상 (약 4분, 고도화 전/후)

- "이 도구는 뉴스 RSS와 정책 자료에서 문서를 모아, 키워드 사전에 있는 표기가 나온 문서를 세어 대시보드로 보여 줍니다."
- "서버가 없고 내 컴퓨터에서 실행합니다. 수집한 자료는 저장소에 올라가지 않습니다."
- (공개 데모 화면) "지금 보시는 것은 지어낸 샘플 데이터로 만든 데모입니다."

### 2. 전 — 수업일(10/17) 시점 (0:30 ~ 1:15)
- (옛 화면) "수업일 시점의 대시보드입니다. 같은 샘플 데이터를 넣었습니다."
- "키워드 순위와 막대만 있고, 일간·주간·월간을 골라야 합니다. 오늘 자료가 없으면 빈 화면이 나옵니다."
- "뉴스와 정책을 어떻게 다른지, 평소와 무엇이 달라졌는지는 알 수 없었습니다."
- "정책 자료는 국가 구분이 없어서 한국·미국·중국이 한꺼번에 섞여 있었습니다."

### 3. 후 ① — 기간을 입력해 수집 (1:15 ~ 2:00)
- (터미널) "이제 `python monitor.py`를 실행하면 조회할 기간을 묻습니다."
- "기간을 입력하면 뉴스와 정책을 수집하고, 끝나면 요청한 기간과 실제 확보한 기간을 나란히 알려 줍니다."
- "뉴스 피드는 최근 기사만 주기 때문에 먼 과거는 비어 있을 수 있습니다. 이 한계를 숨기지 않고 보여 줍니다."
- (화면에는 요약 줄만 보인다. 실제 수집 화면은 길게 띄우지 않는다)

### 4. 후 ② — 한 화면 대시보드 (2:00 ~ 2:50)
- (데모) "카드 격자 한 화면입니다. 조회 기간 전체를 처음에 요약합니다."
- "정책 국가별 키워드에서 나라마다 키워드가 나온 문서 비중을 봅니다. 문서 수가 다른 나라끼리 견줄 수 있게 비중으로 보여 줍니다."
- (정책 선택) "정책 문서 목록에는 문서마다 검출된 키워드가 칩으로 붙습니다. 키워드가 없는 문서는 그렇게 표시해서 왜 비어 보이는지 알 수 있습니다."
- (주간 선택) "주간으로 바꾸면 평소와 달라진 키워드와 뉴스·정책 차이가 나옵니다. 뚜렷함과 참고용으로만 구분하고 중요도는 판정하지 않습니다."

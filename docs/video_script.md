# 시연 영상 대본

영상은 두 개다. **README용**(짧게, 승인 PR용)과 **LMS 제출용**(중간 과제, 고도화 전/후). 화면에는 합성 데모(공개 주소)와 터미널만 쓴다. 직접 수집한 실제 대시보드는 기사·문서 제목이 보이므로 영상에 길게 띄우지 않는다.

- 공개 데모: https://hyeon0.github.io/policy-tech-trend-monitor/
- 수업일(10/17) 시점 화면: 같은 합성 데이터로 옛 코드(`3965f54`)에서 만든 파일을 쓴다(`python dashboard/app.py --dir data/demo --out 옛화면.html --no-validate`를 옛 커밋에서 실행)
- 비교 링크: README 맨 위

## 녹화 전 준비

1. 다른 창·알림을 끈다. 터미널 경로에 사용자 이름이 보이면 `cd`로 짧은 폴더로 옮기거나 프롬프트를 지운다
2. 브라우저는 시크릿 창으로 연다(북마크·계정 표시가 안 보이게)
3. 터미널 글자를 크게 한다. 화면은 브라우저 창만 잡는다
4. 합성 데모에서는 "샘플 데이터 데모" 띠가 위에 보인다. 그대로 두고 "지어낸 자료"라고 말한다

## B. LMS 제출용 영상 (약 5분, 고도화 전/후)

### 1. 도구 소개 (0:00 ~ 0:30)
- "이 도구는 뉴스 RSS와 정책 자료에서 문서를 모아, 키워드 사전에 있는 표기가 나온 문서를 세어 대시보드로 보여 줍니다."
- "서버가 없고 내 컴퓨터에서 실행합니다. 수집한 자료는 저장소에 올라가지 않습니다."
- (공개 데모 화면) "지금 보시는 것은 지어낸 샘플 데이터로 만든 데모입니다."

### 2. 대시보드가 하는 일 — 기능 소개 (0:30 ~ 1:15)
- (데모 맨 위) "이 대시보드가 보여 주는 것을 세 가지로 말씀드리겠습니다. 첫째, **무엇이 많이 언급됐는지**, 둘째, **평소와 무엇이 달라졌는지**, 셋째, **뉴스와 정책, 그리고 정책의 나라별로 어떻게 다른지**입니다."
- (한눈에 보기) "맨 위 한눈에 보기에서는 분석한 문서 수, 뉴스와 정책의 비율, 검출된 키워드 수와 1위 키워드를 한 문장으로 요약합니다."
- (많이 언급된 키워드) "키워드 순위는 그 키워드가 나온 문서가 몇 건인지로 매깁니다. 키워드를 누르면 근거가 된 문서, 함께 나온 키워드, 출처, 실제로 쓰인 표기를 볼 수 있습니다. 숫자가 어디서 나왔는지 확인할 수 있다는 점이 중요합니다."
- (자료 구성) "자료 구성에서는 어느 출처에서 몇 건을 분석했는지 보여 줍니다."
- (정책: 국가별 키워드, 정책 문서) "정책은 한국, 미국, 중국으로 나눠서 나라마다 어떤 키워드가 얼마나 나오는지 비교하고, 정책 문서 목록에서 문서별로 검출된 키워드를 확인합니다."
- (평소와 달라진 키워드, 흐름) "일간, 주간, 월간으로 바꾸면 평소와 달라진 키워드와 날짜별 흐름이 나오고, 뉴스와 정책의 차이, 분야별 보기도 있습니다."
- "모든 차트에는 표로 보기가 있고, 제목 옆 물음표를 누르면 읽는 법이 나옵니다. 이 숫자는 언급량이며 기술의 중요도나 전망이 아니라는 점은 화면에 계속 적어 두었습니다."

### 3. 전 — 수업일(10/17) 시점 (1:15 ~ 1:50)
- (옛 화면) "수업일 시점의 대시보드입니다. 같은 샘플 데이터를 넣었습니다."
- "키워드 순위와 막대만 있고, 일간·주간·월간을 골라야 합니다. 오늘 자료가 없으면 빈 화면이 나옵니다."
- "뉴스와 정책을 어떻게 다른지, 평소와 무엇이 달라졌는지는 알 수 없었습니다."
- "정책 자료는 국가 구분이 없어서 한국·미국·중국이 한꺼번에 섞여 있었습니다."

### 4. 후 ① — 기간을 입력해 수집 (1:50 ~ 2:30)
- (터미널) "이제 `python monitor.py`를 실행하면 조회할 기간을 묻습니다."
- "기간을 입력하면 뉴스와 정책을 수집하고, 끝나면 요청한 기간과 실제 확보한 기간을 나란히 알려 줍니다."
- "뉴스 피드는 최근 기사만 주기 때문에 먼 과거는 비어 있을 수 있습니다. 이 한계를 숨기지 않고 보여 줍니다."
- (화면에는 요약 줄만 보인다. 실제 수집 화면은 길게 띄우지 않는다)

### 5. 후 ② — 한 화면 대시보드로 바뀐 점 (2:30 ~ 3:20)
- (옛 화면과 새 화면을 번갈아) "전에는 순위 막대와 표뿐이었는데, 지금은 카드 격자 한 화면에서 위에서 아래로 읽습니다. 긴 설명문은 물음표로 옮기고, 알림은 한 줄 칩으로 줄였습니다."
- "기간 단위 맨 앞에 조회 기간 전체를 넣어서, 입력한 기간을 한 번에 요약합니다."
- "정책은 나라별 키워드와 문서 목록을 새로 넣었습니다. 정책이 비어 보인다는 지적에 대응한 것입니다."
- (주간 선택) "주간으로 바꾸면 평소와 달라진 키워드가 점 두 개로 나옵니다. 회색은 평소, 파란색은 이번 기간이고, 뚜렷함과 참고용으로만 구분하며 중요도는 판정하지 않습니다."

# 소개 영상 (52초)

이 도구가 무엇을 보여 주는지 52초로 설명하는 자동 재생 페이지다. `index.html` 을 브라우저로 열면 된다.

## 무엇으로 만들었나

| 항목 | 내용 |
|---|---|
| 화면 | 공개 데모 대시보드(`docs/index.html`)를 2026-10-22에 캡처한 5장 |
| 음성 | B가 직접 녹음 (50.5초) |
| 재생 | 「음성과 함께 재생」을 누르면 음성 시각에 맞춰 화면이 넘어간다. 멈췄다 이어 재생해도 어긋나지 않는다. 버튼을 누르지 않으면 소리 없이 자동 반복 |

## 장면 구성

| 시각 | 화면 | 하는 말 |
|---|---|---|
| 0.0초 | 첫 화면 (한눈에 보기) | 51일 동안 669건을 읽고 기술 용어 17개를 찾았다 |
| 7.5초 | 많이 언급된 키워드 | 인공지능 188건으로 1위, AI 에이전트·사이버보안이 뒤를 잇는다 |
| 17.5초 | 근거 문서 | 키워드를 누르면 어느 글에서 나왔는지 날짜·출처까지 열린다 |
| 27.5초 | 뉴스 vs 정책 | 생성형 AI는 뉴스에만, 양자기술은 정책에만 나왔다 |
| 36.5초 | 나라별 키워드 | 한국은 디지털 전환, 미국은 양자기술, 중국은 반도체 |
| 44.5초 | 마무리 | 이 숫자는 언급량일 뿐 중요도가 아니다 |

## 지킨 것

- 화면의 숫자는 모두 **그 대시보드에 실제로 보이는 값**이다. 지어낸 수치가 없다
- 대시보드가 **샘플 데이터로 만든 데모**이므로, 페이지 아래에 그 사실을 적었다
- 재배포가 제한된 출처는 캡처에서도 `제목 비공개` 로 나온다(3번 장면). 가리지 않고 그대로 보여 준다
- "급증", "유망", "미래 예측", "정확도 ○○%" 같은 판정 표현을 쓰지 않았다 (`CLAUDE.md` 규칙 6)
- 나라별 장면은 **그 나라 정책 문서에 어떤 낱말이 많이 나왔는지**만 말한다. 기술력의 앞뒤를 말하지 않는다

## 영상 파일로 만들려면

브라우저에서 전체 화면으로 띄우고 `Windows` + `Alt` + `R` 로 52초를 녹화하면 소리까지 담긴다.

## 다시 만들 때

대시보드가 바뀌면 `shots/` 의 캡처와 `index.html` 의 숫자를 함께 고쳐야 한다. 장면 경계는 `index.html` 의 `CUTS` 배열(초 단위)이고, 음성을 다시 녹음하면 그 값을 맞춰야 한다.

실제 수집 결과와 합성 샘플을 섞지 않도록 영상 아래에 둘을 구분해 적었다.

## 지킨 것

- 화면의 숫자는 모두 **그 대시보드에 실제로 보이는 값**이다. 지어낸 수치가 없다
- 대시보드가 **샘플 데이터로 만든 데모**이므로, 페이지 아래에 그 사실을 적었다
- 재배포가 제한된 출처는 캡처에서도 `제목 비공개` 로 나온다. 가리지 않고 그대로 보여 준다
- 실제로 수집한 자료의 **제목·본문은 쓰지 않았다**. 건수와 기간만 말한다
- "급증", "유망", "미래 예측", "정확도 ○○%" 같은 판정 표현을 쓰지 않았다 (`CLAUDE.md` 규칙 6)
- 나라별 장면은 **그 나라 정책 문서에 어떤 낱말이 많이 나왔는지**만 말한다. 기술력의 앞뒤를 말하지 않는다

## 영상 파일로 만들려면

브라우저에서 전체 화면으로 띄우고 `Windows` + `Alt` + `R` 로 2분 7초를 녹화하면 소리까지 담긴다.

## 다시 만들 때

- 장면 경계는 `index.html` 의 `CUTS` 배열(초 단위)이고, `TOTAL` 은 녹음 길이다. 녹음을 다시 하면 두 값을 맞춰야 한다
- 음성이 화면보다 일정하게 빠르면 `OFFSET` 을 양수로 올린다
- 「다시 녹음한 파일로 바꾸기」로 다른 녹음을 올려 미리 맞춰 볼 수 있다. 그 파일은 브라우저 안에만 있고 저장소에 올라가지 않는다
- 대시보드가 바뀌면 `shots/` 의 캡처와 `index.html` 의 숫자를 함께 고쳐야 한다
